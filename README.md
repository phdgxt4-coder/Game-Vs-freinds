# Battle Zone — Foundation

Done: movement & camera, arena map, animated character (TPS + full-body FPS), footsteps/landing audio.
Next: weapons (shooting, recoil, reload, hit effects), bots, networking, minimap, props in the arena.

src/config.js, src/assets.js   tunables / asset registry
src/core/                      math, fixed-timestep Loop
src/input/                     InputState, TouchControls (dynamic stick, multi-touch), KeyboardMouse (dev), stickMath
src/world/                     World (AABB), MeshWorld (triangle mesh collision, used by the arena), Level (test range: ?level=test)
src/systems/                   CharacterController, CameraRig (pure logic, no renderer dependency)
src/render/                    GameRenderer, MapVisual (GLB loader), CharacterModel (rigged GLB + animation mixer + aim pitch), Avatar (capsule fallback)
src/systems/Locomotion.js      picks the animation clip from motion state; FootstepSystem.js: step events from stride phase
src/audio/                     AudioManager (Web Audio, random variants) + manifest of sound banks
assets/characters/             hazmat.glb (player), enemy.glb (opponents) — rigged, 14+ animation clips
assets/audio/                  Kenney Impact Sounds (CC0) converted to mp3 for iOS/Android
assets/maps/                   tdm_map.glb + tdm_map.collision.json (generated by tools/convert_map.py)
tools/convert_map.py           spec-gloss -> metal-rough conversion, collision triangles, spawn pads
firebase/database.rules.json   Realtime Database rules (paste into Firebase console -> Realtime Database -> Rules -> Publish)
tests/                         `npm test`: import/export check + logic tests on both collision worlds and the real map

Serve over HTTP(S). ES modules + import map: Chrome 89+ / Safari 16.4+.
